# ODE 광고 통합 대시보드 — 시작 패키지

## 현재 제공물의 범위
- `frontend/index.html`: 반응형 대시보드 시제품. CSV/XLSX 파일을 브라우저에서 열어 열 이름/샘플 행을 확인하고, 표와 CSV 내보내기를 시험할 수 있습니다.
- 이 시제품은 **실제 계정에 연결되지 않았으며**, 업로드 데이터를 서버에 저장하지 않습니다. SA API 자동 수집, 계정 로그인/권한, 지속적인 저장은 백엔드 구축 및 배포 설정 후에만 가능합니다.
- 실제 ODE 원본 SA/GFA 보고서가 제공되지 않아 열 매핑 및 식별자 연결은 아직 확정하지 않았습니다.

## 추천 운영 구성
1. 프런트엔드: GitHub Pages (화면만 공개)
2. 백엔드 API/스케줄러: Cloudflare Workers 또는 별도 서버리스 함수 / 예약 실행
3. 데이터베이스: Supabase Postgres 등 접근 제어 가능한 DB
4. 인증: 관리자 로그인 + DB/RLS 정책. 공개 GitHub Pages에 비밀키나 광고 데이터를 넣지 않음.
5. 일일 SA 수집: 서버에서만 네이버 검색광고 API 서명 생성·요청. 계정별 API 권한과 실제 제공 지표를 확인한 뒤 구현.
6. GFA 업로드: 로그인한 관리자가 백엔드로 파일 전송 → 원본 파일 해시/기간/보고서 유형 기록 → 검증 → staging 저장 → 승인 후 반영.

## 데이터 집계 원칙
- SA 키는 날짜 + 계정 + 보고서 단위 + 캠페인/그룹/키워드 식별자로 설계하되, 실제 API 응답 필드 확인 후 확정합니다.
- GFA 원본은 `campaign`, `adgroup`, `product_advshopping`, `product_boostup` 등 **서로 다른 fact table 또는 report_type**으로 분리합니다.
- 캠페인/그룹/상품 보고서를 한꺼번에 더하지 않습니다. 전체 KPI는 우선 캠페인별 보고서 등 단일 기준을 지정하고, 기간/필터가 일치하는지 검증합니다.
- 재수집은 upsert(같은 고유키 덮어쓰기) 방식, 업로드는 SHA-256 파일 해시와 보고서 유형/기간으로 중복 감지합니다. 전환 갱신을 위해 재수집 가능한 최근 기간을 다시 가져옵니다.
- 원본에 없는 값은 NULL로 보관하고 화면에는 `미제공`으로 표시합니다. 연결할 공통 ID가 없으면 억지로 매핑하지 않습니다.

## 다음 단계에 필요한 자료
1. 네이버 SA API: API License, Secret Key, Customer ID (비밀키는 채팅이나 GitHub에 올리지 말고, 배포 플랫폼의 Secret 설정에 입력)
2. SA API 계정 권한과 호출 가능한 보고서/지표 확인
3. GFA 보고서 원본 파일 4종: 캠페인별, 광고그룹별, 상품별 ADV쇼핑, 상품별 부스트업. 가능하면 같은 기간으로 다운로드.
4. 각 보고서의 조회 기간, 시간대, 전환 기준/기여 기간이 보이는 다운로드 설정 또는 캡처
5. 접속할 사용자와 권한 구분(예: 관리자만)

## 최초 배포 안내(프런트엔드 시제품)
1. GitHub에서 비공개 저장소를 만들고 `frontend/index.html`을 업로드합니다.
2. Settings → Pages에서 배포 브랜치와 폴더를 선택합니다.
3. **주의:** GitHub Pages는 공개 정적 사이트이므로 실제 광고 데이터, API 키, Secret을 HTML/JS에 넣지 마세요. 실제 운영 시 화면을 인증 가능한 호스트에 두거나, Pages는 UI만 두고 모든 데이터 요청을 인증된 백엔드로 보내야 합니다.
4. 현재 시제품은 업로드 파일을 서버에 저장하지 않습니다. 브라우저를 닫으면 업로드 데이터는 유지되지 않습니다.

## 주기·오류 확인
- 자동 수집 주기는 백엔드 스케줄러의 cron 설정에서 변경합니다. 예: 매일 오전 7시 KST는 UTC 22:00 전날 기준이므로 시간대 변환을 주의합니다.
- 로그에는 실행 시각, 기간, 보고서 종류, API 상태 코드, 행 수, 오류 메시지를 남깁니다. Secret/토큰은 로그에 기록하지 않습니다.
- 인증 실패: 키/Secret/Customer ID 및 서명 시간 확인. 데이터 누락: API 보고서 상태/기간/권한 확인. 중복: 고유키와 업서트 로그 확인. 전환 변동: 최근 귀속기간 재수집 및 전환 정의 확인.

## 비용 안내
- 이 HTML 시제품은 별도 서버 비용 없이 로컬에서 확인할 수 있습니다.
- GitHub Pages는 공개 정적 화면의 무료 호스팅에 적합하지만, 비밀정보 보관·백엔드 작업·DB·인증을 대신하지 않습니다.
- 백엔드/DB의 무료 구간은 서비스 정책과 사용량에 따라 달라집니다. 실제 사용량과 보안 요구가 정해지기 전에는 월 비용을 확정할 수 없습니다. 배포 전 선택한 제공자의 현재 요금과 무료 한도를 확인하세요.
